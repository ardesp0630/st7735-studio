# ST7735 Studio

> 在线设计 ESP32 TFT 屏幕界面 —— 拖拽布局 · 模板库 · 图片转点阵 · 代码生成

一个**纯网页**的 ST7735S（160×128）界面设计器。打开就能用，无需安装、无需联网。

```
设计界面  →  导出 Arduino 代码  或  蓝牙实时下发到设备
```

---

## 为什么做这个

给 ESP32 配小屏幕时，调布局要**改代码 → 编译 → 烧录 → 看一眼 → 再改**，
一个简单的界面能来回折腾几十次。

这个工具把循环缩短成：**拖一下 → 看效果 → 导出代码**。

---

## 功能

| 功能 | 说明 |
|---|---|
| **可视化布局编辑器** | 10 种元素（文本/矩形/圆角/圆/三角/线/图标/位图/进度条/柱状图），拖拽定位、拖角缩放 |
| **界面模板库** | 6 套预设（余额屏/极简大字/时钟/仪表盘/传感器/空白），一键载入后继续编辑 |
| **图片转点阵** | 导入 PNG/JPG → 自动二值化 → 生成 `PROGMEM` C 数组，带阈值/反色/尺寸调节 |
| **配色工具** | 取色器 + RGB565 转换 + 对比度检查 + 4 套主题色板 |
| **代码生成** | 输出可直接编译的 Arduino 代码（渲染函数 / 完整 .ino / 布局 JSON / 配色宏） |
| **布局 JSON** | 配合参考固件，可蓝牙下发到设备**实时重排，无需重新烧录** |

## 快速开始

### 方式一：直接用（推荐）

打开 `index.html` 即可。或者部署到 GitHub Pages：

```
Settings → Pages → Source: main → /(root) → Save
```

访问 `https://ardesp0630.github.io/st7735-studio/`

### 方式二：本地运行

```bash
git clone https://github.com/ardesp0630/st7735-studio.git
cd st7735-studio
python -m http.server 8000
# 打开 http://localhost:8000
```

> 用 `file://` 直接打开也可以，但部分浏览器会限制 ES Module，建议用 http 服务。

## 使用流程

1. **「模板」页** 选一个模板，或从空白开始
2. **「设计」页** 拖动元素、调整颜色/字号/数据绑定
3. **「图标」页** 需要自定义图标时，导入图片转点阵
4. **「代码」页** 复制生成的 Arduino 代码
5. 粘贴进工程，改引脚，编译烧录

## 固件集成

### 方案 A：导出代码（不需要 BLE）

「代码」页 → 「完整 .ino」→ 复制 → 粘贴进工程。

生成的代码包含：

- 配色宏（`#define P_BG 0xCE16` 等）
- 元素数组定义
- `renderScreen()` 渲染函数
- 数据占位（`curTotal`、`estTokens` 等，替换为你的真实数据源）
- 图标绘制函数 `drawIcon()`

### 方案 B：BLE 实时下发（推荐调试用）

烧录 `firmware/st7735_studio_demo.ino`，然后网页通过蓝牙发送布局。

**BLE 协议：**

```
服务  d5f10001-6f2a-4b6f-9a2a-8b0e2b7f9c01
├ 命令特征 d5f10005-...  (WRITE)
│   LAYOUT      查询布局 → 返回 "0|<总片数>|<第0片>"
│   LAYOUT:N    返回第 N 片
│   PING        连通性检测
└ 设置特征 d5f10007-...  (WRITE)
    分片格式 <seq>|<total>|<内容>
    收齐后解析 {"elems":[...]}
```

**为什么分片？** BLE 默认 MTU 只有 23 字节，一个 21 元素的布局约 850 字节，
必须拆片传输（每片 180 字符），否则连接会断开。

## 元素 JSON 格式

```json
{
  "elems": [
    { "t": 2, "x": 2, "y": 16, "w": 156, "h": 32, "c": "card", "r": 5 },
    { "t": 0, "x": 24, "y": 19, "w": 112, "h": 26, "c": "ink", "sz": 3, "bind": 1 },
    { "t": 8, "x": 10, "y": 44, "w": 140, "h": 4, "c": "acc" }
  ]
}
```

| 字段 | 含义 | 取值 |
|---|---|---|
| `t` | 类型 | 0文本 1矩形 2圆角 3圆 4三角 5线 6图标 7位图 8进度条 9柱状图 |
| `x,y,w,h` | 位置尺寸 | 像素，屏幕 160×128 |
| `c` | 颜色 | 主题色名（`ink`/`acc`/`card`…）或 `#RRGGBB` 或 RGB565 数字 |
| `sz` | 字号 | 1-4（仅文本） |
| `r` | 圆角 | 像素（仅圆角矩形） |
| `bind` | 数据绑定 | 0-17，见上表 |
| `icon` | 图标 | 0-13 |
| `on` | 显隐 | 1/0，省略即显示 |
| `text` | 静态文字 | 字符串（未绑定时用） |

## 组合色板

| 名称 | 背景 | 卡片 | 强调 | 文字 |
|---|---|---|---|---|
| 报纸 | `#C9C2B0` | `#F5F1E6` | `#8C5A2B` | `#1F1B14` |
| 深海蓝 | `#08131E` | `#2A6A96` | `#2FB6E8` | `#EAF6FF` |
| 终端绿 | `#000000` | `#00230F` | `#00E676` | `#00FF88` |
| Nord | `#2E3440` | `#434C5E` | `#88C0D0` | `#ECEFF4` |

**小屏配色建议**（实战教训）：

- ✅ **拉大明度差**，别只靠色相区分 —— 廉价 TN 屏色相还原弱，同明度的色会糊成一片
- ✅ **卡片底色要比背景亮/暗至少 25% 明度**，否则分不出层次
- ✅ 用「配色」页的**对比度检查**，低于 1.8 的方案在小屏上基本看不清
- ❌ 避免大面积高饱和纯色（`#FF0000`/`#00FF00`）—— 刺眼且失真

## 已知限制

- **中文需要自备字库**：Adafruit_GFX 不带中文，生成的代码用 `drawCN()` 占位，
  你需要提供点阵字库或改用英文/数字
- **位图是 1-bit**：单色，可换色但不能显示灰度/彩色照片
- **BLE 需要 HTTPS 或 localhost**：`file://` 下 Web Bluetooth 不可用
- **不做自动布局**：元素位置全靠手拖，没有流式布局

## 目录结构

```
st7735-studio/
├── index.html              主界面
├── css/style.css
├── js/
│   ├── app.js              主控逻辑
│   ├── elements.js         元素模型与数据绑定定义
│   ├── canvas.js           渲染引擎（绘制原语对应 GFX）
│   ├── templates.js        界面模板库
│   ├── bitmap.js           图片转点阵
│   ├── codegen.js          Arduino 代码生成
│   └── index.js            模块出口
├── firmware/
│   └── st7735_studio_demo.ino   参考固件（BLE 接收布局）
└── README.md
```

**改代码时注意**：`elements.js` 里的类型/绑定/图标枚举
必须与 `firmware/st7735_studio_demo.ino` 中的 `enum` **保持一致**，
三处（编辑器 / 代码生成器 / 固件）用的是同一套定义。
