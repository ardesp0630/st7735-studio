Arduino 代码

这是什么

一个纯网页的 ESP32 TFT 界面设计器，无需安装、无需联网（离线可用）。

设计好的界面可以：

  • 导出 Arduino 代码，直接粘贴进你的工程
  • 导出 布局 JSON，通过蓝牙发给支持该协议的固件
快速上手
1
打开「模板」页选一个模板，或从空白开始
2
在「设计」页拖动元素、调整颜色和字号
3
需要图标就去「图标」页导入图片转点阵
4
到「代码」页复制生成的 Arduino 代码
5
粘贴进工程，按你的接线改引脚，编译烧录
常见问题
生成的代码能直接用吗？
能编译。数据部分是占位（余额、Token 等），需要你接入真实数据源。 代码里已标注位置。
中文显示不出来？
Adafruit_GFX 不带中文字库。生成的代码用 drawCN() 占位， 你需要自己提供点阵字库（或改用英文/数字）。
引脚不一样怎么办？
生成的代码顶部有 #define TFT_CS 等宏，改成你的接线即可。 ST7735 与 ESP32 是普通 SPI，引脚可任意映射。
布局 JSON 怎么发给设备？
需要固件支持该协议。本仓库 firmware/ 目录提供了一个 参考实现，通过 BLE 接收 JSON 并实时重排。
为什么颜色看起来和屏幕不一样？
浏览器是真彩色，而 ST7735 是 RGB565（16 位）。预览时会做量化模拟， 但廉价 TN 屏还有额外色偏，最终以实机为准。
